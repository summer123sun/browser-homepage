# 起始页 · browser-homepage · 藏书阁

一个自用浏览器「起始页 / 主页」。**零外部请求**：不引用任何 CDN、Google Fonts、jsDelivr、unpkg、iconfont、favicon 外链服务，也没有第三方统计埋点。断网状态下页面完整可用。

技术栈：纯 HTML + CSS + 原生 JS（ES2020），无构建工具、无 npm 依赖、无后端。所有数据存在浏览器 `localStorage`。

视觉概念：**中性极简 · 纯白纸面**。一屏之内只有三样东西——**一个搜索框、一排常用、一排分类标签**。没有照片背景（可选）、没有毛玻璃、没有渐变、没有阴影堆叠。信息之外一律安静。

> v4 说明：上一版是「整屏摄影背景 + 磨砂玻璃控制台 + 多列书架平铺 106 条链接」，实测太乱。本版把它重构成三段式：链接全部收进可折叠的分类标签，搜索框只做搜索，常用工具按真实点击频率自动浮到前面。


用 Chrome / Edge / Firefox 打开即可，然后把该页面设为浏览器主页。

**方式 B：本地静态服务器（推荐）**

部分浏览器对 `file://` 协议下的 `localStorage` 有限制（Safari 会直接抛安全错误），用本地服务器打开可获得完整的保存/读取能力：

```powershell

```

然后访问 `http://127.0.0.1:8080/`。

> 说明：页面里的所有链接数据都是**用户数据**，其中的 `https://` 是链接目标地址，不是页面自身的资源引用；页面加载的 CSS/JS/图标全部为本地文件或内联 SVG，背景图也是 `assets/` 下的本地相对路径，断网也能正常渲染。

## 四、常用行是怎么排的

顺序完全确定、可预测，三层规则依次生效：

1. **用户钉住的链接**（`xyai.homepage.pins.v1`）永远在最前；
2. **有过点击记录的链接**，按点击次数降序，次数相同按最近点击时间降序；
3. 以上不足 8 个时，用预置种子补齐：`Google 学术 / arXiv / 百度 / Google / GitHub / ChatGPT / Perplexity / Zotero`（种子只在用户还没点够时占位，**一旦用户点了某个链接，该链接就按次数插到前面**）。

瓦片上限 **10 个**（移动端横向滚动）。**任何地方点开链接都计数**：常用瓦片、展开卡片里的链接行，点一次 +1，写入 `xyai.homepage.usage.v1`。

> 计数键是 `站点名|网址`。`data.js` 里的链接没有稳定 id，用这对字段做键，重置数据后计数也不会错位。

## 六、背景图片

### 6.1 必须放在 `assets/`，且必须本地加载

> ⚠️ **硬性约束**：`assets/` 下的 5 个文件名**必须严格一致**，且**只能本地加载**。
> `index.html` / `styles.css` / `app.js` 里**不允许**出现任何指向 `http://` 或 `https://` 的资源引用
> （`data.js` 里的站点 URL 是**链接数据**，不算外链资源）。

| 文件名 | 主题 | 兜底渐变 |
| --- | --- | --- |
| `assets/bg-aurora.jpg` | 深蓝极光山脊 · 夜 | `linear-gradient(160deg,#0B1B33 0%,#123A5C 45%,#0A1424 100%)` |
| `assets/bg-stacks.jpg` | 图书馆书架 · 暖褐 | `linear-gradient(160deg,#3A2A1E 0%,#5C4231 45%,#241A12 100%)` |
| `assets/bg-dune.jpg` | 沙丘暖光 · 昼 | `linear-gradient(160deg,#E8C89A 0%,#D9A970 45%,#B8814B 100%)` |
| `assets/bg-rain.jpg` | 雨夜玻璃 · 冷调 | `linear-gradient(160deg,#0E1A26 0%,#17324A 45%,#08111C 100%)` |
| `assets/bg-nebula.jpg` | 星云 · 深空 | `linear-gradient(160deg,#1A1030 0%,#3B1F55 45%,#0D0718 100%)` |

**默认是「无背景」**——纯白纸面，背景层完全不参与（scrim 透明度为 0）。用户切到有背景时才生效，图片层上方压一层纸色 scrim 保证正文可读。

### 6.2 容错：图片缺失不会破图

背景层用两层叠放：

```css
background-image: url("assets/bg-aurora.jpg"), linear-gradient(160deg,#0B1B33 0%,#123A5C 45%,#0A1424 100%);
```

**图片在上、近似渐变在下**。图片文件缺失或加载失败时，底层渐变直接露出 —— 不会出现破图图标，页面也不会塌陷。
面板里的缩略芯片用同一套叠层；加载失败的芯片会显示为斜纹（`.bg-chip.is-missing`）。

### 6.3 背景微调

- **亮度** 0.3 – 1.4（默认 1）、**模糊** 0 – 20px（默认 0），作用在背景图层上（`filter: brightness() blur()`）。
- 两个值都会持久化到 `localStorage`。

## 七、视觉与动效

### 7.1 记忆点：安全印鉴 Stamp

每条链接右侧一个**方形印章**（不是圆点），像盖过的骑缝章：

- `safe` —— 极安静的浅灰描边方块（`--ink-3`，透明度 .42），刻意不抢眼；
- `caution` —— 琥珀棕（`#B4530B`）2px 描边方块，带 -6° 旋转与半透明墨迹底，**悬停或聚焦显示那条 `note` 提示文案**；
- `pending` —— `--ink-3` 空心方框。

这个动效**只做一处**，其余地方保持安静。

## 八、怎么改数据

数据在 **`data.js`** 里，结构如下：

```js
window.DEFAULT_DATA = {
  version: 1,
  categories: [
    {
      id: 'search',            // 分类唯一 id
      name: '搜索',            // 分类显示名
      tag: 'SEARCH',           // 等宽小标签（自动大写显示）
      color: '#2C5CC5',        // 分类色（保留字段，当前版不在主视觉区着色）
      links: [
        {
          name: '百度',        // 站点名
          url: 'https://www.baidu.com',
          desc: '中文搜索首选', // 一行灰色描述
          safety: 'pending'    // safe / caution / pending
        }
      ]
    }
  ]
};
```

> **必须写成 `window.DEFAULT_DATA = { … }`**，不要改成顶层 `const DEFAULT_DATA`。
> 经典脚本（非 module）里的顶层 `const`/`let` 只创建脚本作用域绑定，不会成为 `window` 的属性，
> `app.js` 将取不到默认数据，页面会退化成空列表。

字段说明：

- `safety` 三态：
  - `safe` —— 已核实安全，右侧显示安静的浅灰方块印鉴；
  - `caution` —— 谨慎，右侧显示琥珀棕印章，可带 `note: '提示文案'`，悬停或聚焦该印章会显示提示；
  - `pending` —— 未核实，右侧显示灰色空心方框。
- 内置数据集：**15 个分类 / 106 条链接**，其中 72 条已核实安全、34 条需留意（`caution`）、0 条未核实。
  - 含 `research`「学术研究」（26 条）与 `ai-global`「国外 AI 工具」（10 条）两个分类；
  - 海外 AI 入口（ChatGPT / Claude / Gemini / Google 等）**全部标 `caution`**，
    `note` 里写明「需自备代理 / 海外网络」，因为它们在大陆网络下通常不可达；
  - 原 13 个分类 / 70 条链接**一条未删**，所有 `safety` 与 `note` 原样保留（已用脚本逐条比对确认）。
- 新增条目时先按「安全 / 谨慎 / 未核实」给出依据，不要凭感觉标成 `safe`。

改完 `data.js` 后：

- **想立即生效**：在 ⚙ 面板 → 数据 → 「重置为内置默认」→ 二次确认。
- **想保留现有改动**：用「导出 JSON」备份，再把 `data.js` 改好，然后在页面上「导入·覆盖」你的备份（或者直接用编辑模式改）。

> 注意：`data.js` 是默认数据集；你在页面上做的修改保存在 `localStorage`，会覆盖默认数据。「重置」是回到 `data.js` 的唯一入口。

## 九、导出 / 导入

- **导出**：⚙ 面板 → 数据 → 「导出 JSON」→ 浏览器下载 `homepage-links-YYYYMMDD.json`，内容是当前全部数据（含分类、颜色、安全状态）。
- **导入**：两个按钮二选一
  - **导入·覆盖**：用文件内容替换当前全部数据（会二次确认，建议先导出备份）。
  - **导入·合并**：把文件里的分类并入当前数据；同名（同 id 或同名）分类只补充缺失链接，不重复添加，其余分类追加到末尾。
- **导入前校验**：文件必须是合法 JSON、根节点是对象、含 `categories` 数组，每个分类要有 `name` 字符串与 `links` 数组，每条链接要有 `name` 和 `url`。任何一项不满足都会在页面底部提示**具体原因**，不会写入任何数据。

### 主题

CSS 变量集中在 `styles.css` 顶部（见 7.3 的对照表）。

`html[data-theme="auto"]` 走 `prefers-color-scheme` 自动切换，`light` / `dark` 为手动覆盖，选择保存在 `localStorage`。

> `--ink-3` 只用于**装饰性**信息（分类标签、计数、提示脚注）；承载内容的文本一律用 `--ink` / `--ink-2`，以保证 ≥ 4.5:1 对比度。

### 无障碍与兼容

- 语义化结构：分类卡片用 `<article>`，链接用 `<ul>/<li>/<a>`，引擎菜单用 `role="listbox"/"option"` + `aria-selected`。
- 分类标签是可聚焦按钮，带 `aria-expanded` / `aria-controls`；展开状态与面板同步。
- 所有交互元素可 Tab 聚焦，焦点环为 2px `--accent` 外框 + 2px 偏移。
- 尊重 `prefers-reduced-motion`，关闭过渡与动画。
- 响应式断点：`≤900px` 收紧留白；`≤560px` 搜索框竖排三段、常用行与分类标签单行横向滚动（整页不产生横向滚动条）、展开卡片单列。实测 1280 / 900 / 560 三档零横向溢出。
