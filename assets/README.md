# assets/ · 背景图片目录

本目录存放起始页的**背景图片**。图片**必须本地加载**——`index.html` / `styles.css` / `app.js`
中不允许出现任何指向 `http://` 或 `https://` 的外部资源引用（`data.js` 里的站点 URL 是**链接数据**，
不算外链资源）。

## 必须存在的 5 个文件名（大小写敏感）

| 文件名 | 主题 | 兜底渐变 |
| --- | --- | --- |
| `bg-aurora.jpg` | 深蓝极光山脊 · 夜 | `linear-gradient(160deg,#0B1B33 0%,#123A5C 45%,#0A1424 100%)` |
| `bg-stacks.jpg` | 图书馆书架 · 暖褐 | `linear-gradient(160deg,#3A2A1E 0%,#5C4231 45%,#241A12 100%)` |
| `bg-dune.jpg` | 沙丘暖光 · 昼 | `linear-gradient(160deg,#E8C89A 0%,#D9A970 45%,#B8814B 100%)` |
| `bg-rain.jpg` | 雨夜玻璃 · 冷调 | `linear-gradient(160deg,#0E1A26 0%,#17324A 45%,#08111C 100%)` |
| `bg-nebula.jpg` | 星云 · 深空 | `linear-gradient(160deg,#1A1030 0%,#3B1F55 45%,#0D0718 100%)` |

文件名的拼写必须与上表**完全一致**，否则页面会走渐变兜底（不会破图，但看不到照片）。

## 容错机制

- 背景层用 `background-image: url("assets/xxx.jpg"), <渐变>` 两层叠放，**图片在上、渐变在下**。
  图片文件缺失或加载失败时，底层渐变直接露出，页面不会出现破图图标，也不会塌陷。
- 面板里的缩略芯片用同一套叠层；加载失败时芯片会显示为斜纹（`.bg-chip.is-missing`）。
- 另外还有「无背景」选项（纯 `--paper` 底色），用于完全关闭背景图。

## 建议参数

- 格式 JPEG、宽度 ≥ 1920px、16:9 或更宽、文件大小 ≤ 500KB（5 张合计 ≤ 2MB）。
- 画面**不要有明显的文字或高对比焦点**，中央区域会被磨砂玻璃面板盖住。
- 深色照片在亮色主题下会被浅色 scrim 压暗，浅色照片在暗色主题下会被深色 scrim 压暗，
  两套 scrim 都在 `styles.css` 的 `--scrim-*` 变量里。
